# RAD PROJECT

Внутренний веб-планировщик дизайн-студии: контроль клиентских этапов по договорам (сроки, статусы, акты) и синхронизация их с задачами и выплатами подрядчикам.

**Демо:** https://yakyolya.github.io/rad-project/

## Возможности

- Дашборд проектов с прогрессом по завершённым этапам и сигналами «Пора платить»
- Клиентские этапы: вид «Список» и «Таймлайн», inline-редактирование, цветовая кодировка типов
  (оплата — зелёный, частичная оплата — синий, выполняется — жёлтый, акт — красный)
- Подрядчики: привязка к этапу, подсветка завершённого этапа, мигающий бейдж «Пора платить!»
- Все изменения сразу сохраняются в LocalStorage браузера

## Стек

React 18 (UMD + [htm](https://github.com/developit/htm), без сборки), Tailwind CSS (Play CDN), иконки Lucide (inline SVG).

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages. Сборка не нужна.

## Ограничения MVP

Данные хранятся только в браузере пользователя: они не синхронизируются между людьми и устройствами и пропадут при очистке данных сайта.
